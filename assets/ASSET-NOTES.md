# Branding asset

The dragon image was generated using the built-in image generation tool for this project. `dragon.ico` was derived from it with Pillow and contains 16, 24, 32, 48, 64, 128 and 256 pixel Windows icon sizes. It is a new asset, not a reconstruction of an earlier unseen icon.

Prompt: A premium 3D purple dragon holding a white-and-orange Flipper Zero, purple scale detail, glowing violet eyes, curved horns, folded wings, dark square background with subtle emerald falling Matrix-style code and purple glow; balanced centered composition, readable as a Windows icon, no text or watermark.

## v0.2.0 reference artwork

`design-reference.png` is the supplied user design. The application renders selected decorative regions for the dragon mark, title branding, handheld device, Foundation logo, and chip illustrations. All navigation, connection fields, panels, action controls, forms, text areas and live Matrix animation are native Qt widgets or QPainter drawing. SVG field indicators and line icons are code-created assets. No additional AI mockup was generated for this rebuild.
